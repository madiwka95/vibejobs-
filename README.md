# VibeJobs ⚡ — работа для вайб-кодеров

Веб-приложение-агрегатор: hh.ru API + Habr Career + Telegram-импорт.
Только стандартная библиотека Python, без `pip install`.

## Запуск

Проще всего — двойной клик по `start.bat`: сам поднимет сервер и откроет браузер.

Вручную:

```bash
cd vibe-jobs
python app.py
# открыть http://localhost:8000
```

Без сервера тоже работает: в `index.html` вшит слепок реальных вакансий
(обновить: `python bake.py`), фильтры по нему работают локально.

## Выложить в интернет (бесплатно, живое обновление)

1. Зарегистрируйтесь на github.com, создайте репозиторий `vibejobs`,
   загрузите туда все файлы из папки `vibe-jobs` через веб-интерфейс
   (Add file → Upload files). Git устанавливать не обязательно.
2. Зарегистрируйтесь на render.com → New → Web Service → выберите репозиторий.
   `render.yaml` уже лежит в папке — настройки подхватятся сами. Либо вручную:
   Start Command `python app.py --host 0.0.0.0`, план Free.
3. Через пару минут получите ссылку вида `https://vibejobs.onrender.com` — делитесь.

Нюансы бесплатного тарифа: сервер засыпает без посетителей (первая загрузка
~30–60 сек), серверы за рубежом не видят hh.ru (403) — живые данные будут
в основном с Habr Career; вшитый слепок при этом виден всегда и сразу.

Свой запрос к hh.ru:

```bash
python app.py --port 8000 --query "telegram bot junior"
```

Коллектор отдельно (сохраняет `jobs_cache.json`):

```bash
python collector.py --query "python junior" --out jobs_cache.json
```

## Как это работает

Только реальные вакансии, демо-данных нет:

- `collector.py` — тянет hh.ru (официальный бесплатный API; нужен российский IP,
  иначе hh.ru отвечает 403 и источник пропускается), парсит карточки Habr Career
  (заголовок, компания, грейд, город, навыки, зарплата), подмешивает
  `telegram_vacancies.json`, считает `vibe_score` 0–100 и `stack_tags`.
- `app.py` — stdlib HTTP-сервер: отдаёт `index.html` + `/api/jobs`, `/api/stacks`, `/api/refresh`. Кэш 30 мин.
- `index.html` — фильтры: строка поиска, чипы стека, удалёнка, junior-friendly,
  зарплата от, источник, избранное (localStorage). Тёмная/светлая тема (🌙).
  Кнопка «✓ Откликнулся» ведёт историю в «📋 мои отклики».
  Кнопка «✨ Отклик» открывает генератор сопроводительных: 3 тона из коробки,
  опционально — генерация через свой OpenAI-совместимый API-ключ
  (ключ хранится только в браузере).
  Без запущенного бэкенда вакансий нет — страница честно просит запустить `python app.py`.

## Telegram-источник

Публичного API у каналов нет, поэтому так:
1. Вручную/ботом выгружаете посты в `telegram_vacancies.json` в формате:
   ```json
   [{"title": "...", "channel": "@channel", "text": "...",
     "url": "https://t.me/...", "remote": true, "city": "", "date": "2026-09-17"}]
   ```
2. Открываете `/api/refresh` — они появятся с `source=telegram`.
